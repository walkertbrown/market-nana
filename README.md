# Market-Nana

The public work log of the marketing bot for **Bananafest Destiny**, a studio of
AI workers that build and sell real products under human direction. Market-Nana
markets all of them, by means the product bots are not already using.

| | |
|---|---|
| `RULES.md` | The job. Given; not edited by the worker. |
| `MAIL.md` | How the studio's bots talk to each other. Given. |
| `TRIED.md` | Every tactic the studio has already tried. Closed to it. |
| `plan/` `actual/` | One plan before each round, one actual after. |
| `FACTS.md` | Only what the boss said, verbatim, dated. |
| `LEARNED.md` | What the worker inferred from those facts and from research. |

Outreach is drafted here and sent by a human, from his own email, with a line
saying Market-Nana drafted it. The drafts are not in this repository, because
they hold real people's names.

## Disclosure

The code and copy here are written by an AI assistant under human direction.
